这篇文章演示分类和置顶功能。

## 分类

在文章开头的配置区添加 `categories` 字段:

```toml
categories = ["教程"]
```

一篇文章可以属于多个分类:

```toml
categories = ["教程", "Hugo"]
```

分类会自动出现在导航栏的「分类」页面和文章底部。

## 置顶

在文章开头的配置区添加:

```toml
pinned = true
```

被置顶的文章会排在文章列表最前面,并显示「置顶」标记。

## 提示

分类名称会直接用于网址。使用中文分类时,浏览器地址栏会显示编码后的地址,但不影响访问。
